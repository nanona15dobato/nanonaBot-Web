# Bot作業依頼（BOTREQ）からの取り込み

タスク作成画面の「Bot作業依頼から取り込む」は、[Wikipedia:Bot作業依頼](https://ja.wikipedia.org/wiki/Wikipedia:Bot作業依頼) の本文から `{{リンク修正依頼/改名}}` を探し、各ペアを置換ルールに変換して表示します（仕様書7章）。**読み込んだだけではタスクは作られません。** 内容を確認し、「対応済みのN件をルールとして取り込む」を押してから、通常どおりタスクを作成してください。

## 表示されるもの

- **topic listの依頼進捗**: `Wikipedia:Bot作業依頼/topic list` から、依頼ごとの進捗テンプレートの状態を表示します。
- **提案ごとのカード**: `{{リンク修正依頼/改名}}` の呼び出しごとに、`提案=` の内容と、ペアごとの分類結果を表示します。

`{{リンク修正依頼/改名}}` の引数は、奇数番目が改名元、偶数番目が改名先です（[Template:リンク修正依頼/改名/doc](https://ja.wikipedia.org/wiki/Template:リンク修正依頼/改名/doc) の書式）。

## ペアの分類

上から順に判定し、最初に当てはまったものになります。

| 改名元 → 改名先 | なるルール | 備考 |
|---|---|---|
| `X` → `DELETE_PAGE` | [リンク解除](rule-types.md#リンク解除-unlinkpage) | |
| `X` → `REDIRECT_TARGET` | 解決先に応じたルール | 下の「REDIRECT_TARGET」を参照 |
| `Template:X` → `subst:` | [テンプレートのsubst化](rule-types.md#テンプレートのsubst化-templatesubst) | `Template:` の無い改名元は未対応 |
| `http(s)://…` → `http(s)://…` | [外部リンクの付け替え](rule-types.md#外部リンクの付け替え-urlrename) | 片方だけURLのペアは未対応 |
| `X#節{{!}}表示` などを含む | [リンク置換（節・表示名指定）](rule-types.md#リンク置換節表示名指定-linkrenameexact) | Category/Template・ページ名が空（同じページ内の節）のものは未対応 |
| `Category:X` → `Category:Y` | [Category置換](rule-types.md#category置換-categoryrename) | |
| `Template:X` → `Template:Y` | [テンプレート置換](rule-types.md#テンプレート置換-templaterename) | |
| 片方だけ `Category:`／`Template:` | 未対応（名前空間が合わない） | |
| それ以外（通常の記事どうし） | [リンク置換](rule-types.md#リンク置換-linkrename) または [リンク置換2](rule-types.md#リンク置換2表示保持-linkrename2) | 改名元に全角括弧「（」が無く改名先にある場合はリンク置換2（表示を残す） |

未対応のペアは「[未対応: 理由]」として表示し、取り込みません。必要ならタスク作成画面で手動でルールを追加してください。

## REDIRECT_TARGET

`X → REDIRECT_TARGET` は「リダイレクトになっている X へのリンクを、リダイレクト先へ直接リンクするよう直す」という指定です。

1. 読み込み時に、X のリダイレクト先を `action=query&redirects=1` で問い合わせます（ページ名の正規化も辿ります）。
2. リダイレクト先を改名先として、上の表で分類し直します。節へのリダイレクトなら「リンク置換（節・表示名指定）」になります。
3. 画面には「[リンク置換（リダイレクト解決）] X → 解決先 ※取得時点の解決先」と表示します。

- 取り込んだ時点の解決先がルールの改名先として固定されます。その後リダイレクトが付け替えられても追従しません。取り込む前に解決先を確認してください。
- X がリダイレクトでない・存在しない場合は「未対応（REDIRECT_TARGET指定だが改名元がリダイレクトではない）」になります。

# 着手・完了・解決（フェーズ13）

上部メニューの「Bot作業依頼」（`/botreq`、オーナー専用）では、[Wikipedia:Bot作業依頼](https://ja.wikipedia.org/wiki/Wikipedia:Bot作業依頼) の依頼ごとに、作業の着手・完了・解決を記録できます。利用者スクリプト [`userscripts/botreq.js`](../userscripts/botreq.js)（ウィキ上の 利用者:Nanona15dobato/script/botreq.js）と同じ操作で、作る記録の書式も同じです。どちらで着手しても、もう一方で完了・解決できます。

## 一覧

依頼の節（署名つきのコメントがある見出し）を、新しい順に表示します。既定では未解決の依頼だけを表示し、「すべて」で解決済みも表示します。

| 列 | 内容 |
|---|---|
| 依頼 | 節の見出し。クリックするとウィキ上のその節を開きます。小見出しの依頼には「（小見出し）」と付きます |
| 状態 | 節に `{{解決済み}}` があれば「解決済み」。無ければ最後の `{{BOTREQ|…}}` で「着手」「完了」（`済` を含む）、それ以外の引数（`保留` など）はそのまま表示します。どちらも無ければ「未着手」 |
| 依頼者・依頼日時 | 節の中で最も古いコメント（入れ子も含む）の署名。節の冒頭に `{{解決済み}}` の署名があっても、依頼者を取り違えません |
| 作業記録 | 作業記録のページ（`利用者:nanonaBot/依頼/` + 依頼の年）に、この依頼の記録があるか。「着手済み」「完了済み」はクリックで記録のページを開きます |
| 操作 | 次に行う操作のボタンと、「…」メニュー（ほかの操作・この依頼からタスクを作成） |

次に行う操作は、状態と作業記録の両方から決めます: 解決済みなら無し、完了（または記録が完了済み）なら「解決」、着手（または記録が着手済み）なら「完了」、それ以外は「着手」。「…」メニューからは、どの操作もいつでも選べます。

## 各操作

どの操作も、まず保存する内容を作ってダイアログに表示します。**ダイアログを開いただけではウィキは変わりません。** プレビュー・差分・ウィキテキストのタブで確認し、必要ならウィキテキストと要約を書き換えてから「保存」を押します。

| 操作 | 編集するページ | 内容 |
|---|---|---|
| 着手 | 作業記録（無ければ作成） | `{{../head|件数=}}` を1つ増やし、末尾に記録の節を追加します（要約欄・依頼へのリンク・議論場所・依頼者・依頼時刻・着手（準備）時刻）。`<!--sec 節ID|編集回数-->` に、この時点の Bot の編集回数を残します |
| 完了 | 作業記録 | 着手時の編集回数から今までに増えた件数だけ Bot の投稿記録を取得し、着手時刻（最も古い編集）・終了時刻（最も新しい編集）・作業（`{{利用者の投稿記録リンク}}`。5000件ごとに分け、複数なら「の計N編集」）を書き込みます |
| 解決 | Bot作業依頼（その節だけ） | 見出しの直後に `{{解決済み|~~~~}}` を入れます |

- **議論場所**（着手）: 依頼の節のウィキテキストにあるリンクから選べます。ノート・Wikipedia・プロジェクトなど議論の場になる名前空間のページを先に並べ、署名の利用者ページ・テンプレート・この依頼ページ自身は除きます。カテゴリへのリンクは、記録のページがそのカテゴリに入らないよう `[[:Category:…]]` にします。
- **依頼の節へのコメント**（着手・完了）: 着手は `{{BOTREQ|着手}}--~~~~`、完了は `{{at|依頼者}}:{{BOTREQ|完了}} Botにて…行いました。…` を用意します。「コピー」でコピーするか、「保存と同時に、依頼のコメントへの返信として投稿する」をオンにすると、保存のあとに依頼のコメントへの返信として投稿します（DiscussionTools の返信と同じ）。投稿しない場合は、保存するときにコメントをコピーします。完了のコメントの「…が0項目のため」の部分は、必要に応じて書き換えてください。
- 着手では、Bot の編集で使う要約（`Bot:[[…#botreq-n-N|作業依頼]] - 依頼名`）も表示し、保存するときにコピーします。

## 安全のための動き

- 作業記録の編集と依頼への返信は、**運用者のアカウント**（既定は `Nanona15dobato`。BotPassword で設定済みのもの）で行います。署名もこのアカウントになります。アカウントは環境変数 `BOTREQ_ACCOUNT` で変えられます → [設定](configuration.md#bot作業依頼)
- 保存できるのは、Bot作業依頼（節を指定した編集だけ）と作業記録のページだけです。
- ダイアログを開いたときの版を基準に保存します（`basetimestamp`）。その間に誰かが編集していれば「編集が競合しました」となり保存しません。閉じて、もう一度操作してください。作業記録を新しく作る場合に、その間に作られていたときも同様です。
- 次の場合は、ダイアログに注意を表示します: 着手で、この依頼の記録が既にある（続けるともう1つ追加します）／完了で、記録が既に完了している（上書きします）・投稿記録の件数が編集回数の差より少ない（削除された編集など）／解決で、節に既に `{{解決済み}}` がある。
- 次の場合はダイアログを開かずにエラーにします: 完了で、作業記録が無い・この依頼の記録が無い・着手してから Bot の編集が増えていない・増えた件数が10万件を超える。
