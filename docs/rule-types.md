# 置換ルールの種類

タスクは1つ以上の「置換ルール」でできています。ルールごとに、**何を書き換えるか**（置換）と **どのページを対象にするか**（対象の取得）が決まっています。

- [すべてのルールに共通すること](#すべてのルールに共通すること)
- [一覧](#一覧)
- 各ルール: [リンク置換](#どちらも選ばないlinkrename) / [リンク置換2](#表示を保持するlinkrename2) / [節・表示名指定](#節表示名を指定するlinkrenameexact) / [Category置換](#category置換-categoryrename) / [Category除去](#category除去-categoryremove) / [テンプレート置換](#テンプレート置換-templaterename) / [リンク解除](#リンク解除-unlinkpage) / [subst化](#テンプレートのsubst化-templatesubst) / [外部リンクの付け替え](#外部リンクの付け替え-urlrename) / [カスタム](#カスタム-custom)

## すべてのルールに共通すること

- **ページ名の表記ゆれ**: 先頭1文字の大文字・小文字、半角スペースとアンダースコアを同じものとして扱います（MediaWikiのページ名の規則に合わせています）。2文字目以降の大文字・小文字は区別します。
- **書き換えない場所**: `<nowiki>`・`<pre>`・`<math>`・`<syntaxhighlight>`・`<source>`・`<score>`・`<chem>`・`<ce>` の中と、HTMLコメント（`<!-- -->`）の中は変更しません。
- **プレフィックス**: Category系の改名元・改名先に `Category:`（`カテゴリ:`）、テンプレート系に `Template:`（`テンプレート:`）を付けて入力しても、自動で外して扱います。
- **変更が無いページ**: ルールを適用しても本文が変わらないページは編集せず、「スキップ（変更なし）」になります。
- **名前空間の指定**: 「未選択」は全名前空間です。種別ごとに既定値が違います（下の一覧を参照）。

## 一覧

| 種別 | 書き換える内容 | 対象ページの取得 | ウェーブ | 名前空間の既定 |

## リンク置換 `linkRename` / `linkRename2` / `linkRenameExact`

ページの改名（移動）に合わせて、旧ページへのリンクを新ページへのリンクに直します。タスク作成画面では1種類の「リンク置換」で、カードの選択によって次の3通りの動きになります（保存される `templateType` はそれぞれ従来どおり。既存のタスク・複製・API とも互換です）。

| カードの選択 | 動き | `templateType` |
|---|---|---|
| どちらも選ばない | すべての `[[旧…]]` のリンク先を変える（節・表示名はそのまま） | `linkRename` |
| 表示を保持する | 上と同じだが、表示名の無い `[[旧]]` は `[[新\|旧]]` にして見た目を変えない | `linkRename2` |
| 節・表示名を指定する | 指定した節・表示名のリンクだけを付け替える | `linkRenameExact` |

BOTREQからの取り込みでは、ペアの分類（[BOTREQ](botreq.md#ペアの分類)）に合わせて選択が入った状態でカードが作られます（「表示を保持」・「節・表示名を指定」とその内容）。

### どちらも選ばない（`linkRename`）

| 変更前 | 変更後 |
|---|---|
| `[[旧]]` | `[[新]]` |
| `[[旧\|表示名]]` | `[[新\|表示名]]` |
| `[[旧#節]]` | `[[新#節]]` |
| `[[新\|新]]`（置換の結果できたもの） | `[[新]]` |
| `{{See also\|旧}}` などハットノート内の参照 | `{{See also\|新}}` |

- ハットノートの対象: `See also`・`See`・`For`（`For1`/`For2`）・`Main`・`Otheruses`（`Otheruseslist`/`Otheruses2`）・`Other people`・`Other ships`・`混同`（`混同2`）・`Redirect`・`仮リンク`。
- `[[旧]]` は表示も「新」に変わります。表示を「旧」のまま残したい場合は「表示を保持する」を選びます。

### 表示を保持する（`linkRename2`）

| 変更前 | 変更後 |
|---|---|
| `[[旧]]` | `[[新\|旧]]` |
| `[[旧\|表示名]]` | `[[新\|表示名]]` |

BOTREQからの取り込みでは、改名元に全角括弧が無く改名先にある場合（例: `○○` → `○○ (曖昧さ回避)` 型の改名）にこちらが選ばれます。

### 節・表示名を指定する（`linkRenameExact`）

特定の節へのリンクや、特定の表示名のリンクだけを付け替えます。BOTREQの `|改名元#節1{{!}}ラベル |改名先#節2{{!}}ラベル` 形式に対応します。指定したときは「表示を保持」は使えません（表示名は「改名先の表示名」で決めます）。

| 指定 | 対象になるリンク | 結果 |
|---|---|---|
| 改名元の節あり | その節へのリンクだけ（`[[旧#節1]]`・`[[旧#節1\|…]]`） | `[[新#節2…]]` |
| 改名元の節なし（既定の「節なしのリンクだけ」） | 節の無いリンクだけ（`[[旧]]`・`[[旧\|…]]`） | `[[新#節2…]]` |
| 改名元の節を問わない（`fromAnchorAny`） | 節の有無・内容を問わない（`[[旧\|…]]`・`[[旧#どの節でも\|…]]`）。表示名だけで絞りたいときに使う | 改名先の節があればその節、無ければ元の節をそのまま残す（`[[旧#x\|…]]` → `[[新#x\|…]]`） |
| 改名元の表示名あり | その表示名のリンクだけ | 表示名は改名先の表示名（無ければ改名元の表示名） |
| 改名元の表示名なし | 表示名を問わない | 表示名つきのリンクは表示名をそのまま、表示名なしのリンクは改名先の表示名があればそれを付ける |

例: 改名元 `旧記事`、改名先 `新記事#節`・表示名 `旧記事` → `[[旧記事]]` は `[[新記事#節|旧記事]]`、`[[旧記事|別名]]` は `[[新記事#節|別名]]`、`[[旧記事#他]]` は変更なし。ハットノートのテンプレートは直しません。

例（節を問わない）: 改名元 `旧記事`・節を問わない・表示名 `ラベル`、改名先 `新記事`・表示名 `新ラベル` → `[[旧記事|ラベル]]` は `[[新記事|新ラベル]]`、`[[旧記事#節A|ラベル]]` は `[[新記事#節A|新ラベル]]`、`[[旧記事#節A|別]]` は変更なし。

画面では「改名元の節」を「節なしのリンクだけ／節を問わない／指定した節へのリンクだけ」から選びます。

### 対象と、検索での絞り込み（任意）

- **対象**: 旧ページのリンク元（`list=backlinks`）。ウェーブ1はTemplate名前空間、ウェーブ2はその他（既定は標準名前空間）。
- **検索で絞り込む**（`searchNarrowing: true`）: ウェーブ2の対象を、リンク元のうち本文に旧リンクの記述があるページだけにします。リンク元には、テンプレート経由などで本文に `[[旧]]` が書かれていない（取得しても変更不要＝スキップになる）ページも含まれるためです。全文検索
  `linksto:"旧" insource:/(\[\[:?|\|) *旧 *[\]\|\#\}]/`
  （`[[旧…]]` と `{{テンプレート|旧}}` に一致。先頭の文字の大小・空白と下線を同一視）の結果と、リンク元の共通部分を対象にします。実際の例では、リンク元の1〜2割程度が減ります。
  - 次のときは**絞り込まず**、リンク元のすべてを対象にします（実行ログに理由を表示）: 正規表現の検索が時間切れになった（リンクの非常に多いページで起きる）／検索結果が1万件を超える／検索のエラー／改名元が標準名前空間以外（`WP:` などの別名で書かれたリンクを拾いきれないため）／リンク元が50件未満。
  - 検索の索引は、編集から反映まで時間がかかることがあります。最近編集されたページは拾えない（＝直し漏れになる）ことがあるため、既定ではオフです。
  - 絞り込んだ結果（何件のうち何件を対象にしたか）は、ウェーブ2の「対象ページ取得が完了しました」の実行ログに出ます。

## Category置換 `categoryRename`

カテゴリの改名に合わせて、ページのカテゴリを付け替えます。

| 変更前 | 変更後 |
|---|---|
| `[[Category:旧]]`・`[[カテゴリ:旧\|ソートキー]]` | `[[Category:新]]`・`[[Category:新\|ソートキー]]` |
| 付け替えの結果 `[[Category:新]]` が重複したとき | 1つにまとめる |
| `{{リダイレクトの所属カテゴリ\|redirect1=…\|1-1=旧}}` | `1-1=新` |
| ハットノート内の参照 | 新しい名前に |
| （任意）本文中の「Category:旧」の記述 | 「Category:新」 |

**「Category:旧」の記述も置換する**（チェックボックス）: リンクの形かどうかを問わず、`[[:Category:旧]]`・`{{Cat|Category:旧}}`・地の文の `Category:旧` などを置き換えます。別のカテゴリ名の一部になっている箇所（`Category:旧橋梁` 等）や、旧名の直後に和文が区切りなく続く箇所は変更しません。

**対象と順番**（3ウェーブ）:

1. **ウェーブ1**: カテゴリのメンバーのうち **Template名前空間** のページを先に直します。直したテンプレートを使っているページは、null edit（または purge）でカテゴリ所属を更新します。→ [null edit と purge](task-lifecycle.md#null-edit-と-purgecategory系のウェーブ1のあと)
2. **ウェーブ2**: カテゴリのメンバーを取り直し、Template以外の残りを直します（テンプレート経由で入っていたページはもう外れているので、本文に `[[Category:旧]]` があるページだけが残ります）。
3. **ウェーブ3**: **標準名前空間** で、`{{リダイレクトの所属カテゴリ}}` に旧カテゴリ名が構造的に書かれているページを直します。チェックボックスを入れた場合は、カテゴリのリンク元と `insource:"Category:旧"` の検索結果も加えます。

- `{{リダイレクトの所属カテゴリ}}` と旧カテゴリ名の記載があるのに構造的に確認できないページ（想定外の書き方・コメントアウト等）は自動編集せず、「警告」タブに表示します。
- 名前空間を指定した場合、Templateを含まなければウェーブ1は0件になります。ウェーブ3は指定に関係なく標準名前空間だけです。

## Category除去 `categoryRemove`

ページからカテゴリを外します。

| 変更前 | 変更後 |
|---|---|
| `[[Category:旧]]`（前の改行も含めて） | 削除 |
| `{{リダイレクトの所属カテゴリ}}` 内の `N-M=旧` | 引数を削除し、残りを1から番号を詰め直す |

対象と順番はCategory置換と同じです（「Category:旧の記述」の置換はありません）。

## テンプレート置換 `templateRename`

テンプレートの改名に合わせて、呼び出し名だけを置き換えます。引数はそのままです。

| 変更前 | 変更後 |
|---|---|
| `{{旧}}`・`{{ 旧 \|引数}}` | `{{新}}`・`{{ 新 \|引数}}` |

**対象**: テンプレートの使用ページ（`list=embeddedin`）。既定は標準名前空間だけです。テンプレートの中から呼ばれている場合も直すなら、Template名前空間も選んでください。

## リンク解除 `unlinkPage`

削除されたページなどへのリンクを外して地の文にします（BOTREQの `DELETE_PAGE`）。

| 変更前 | 変更後 |
|---|---|
| `[[旧\|表示名]]` | `表示名` |
| `[[旧]]`・`[[旧#節]]` | `旧` |
| `{{See also\|旧\|別}}` | `{{See also\|別}}` |
| `{{See also\|旧}}`（引数が旧だけ） | テンプレートごと削除（その行に呼び出ししか無ければ行ごと） |

- ハットノートは一覧型（`See also`・`Seealso`・`See`・`Main`・`混同`）だけを対象にします。`{{Otheruses}}`・`{{For}}` のように引数ごとに役割が違うものや、`l1=` などの名前付き引数を含む呼び出しは、表示を壊さないよう変更しません。
- **対象**: 旧ページのリンク元（既定は標準名前空間、1ウェーブ）。

## テンプレートのsubst化 `templateSubst`

テンプレートの呼び出しを `subst:` にします（BOTREQの `Template:X |subst:`）。保存時にMediaWikiが展開します。

| 変更前 | 変更後 |
|---|---|
| `{{旧\|引数}}` | `{{subst:旧\|引数}}` |
| `{{subst:旧}}`・`{{safesubst:旧}}` | 変更なし |

**対象**: テンプレートの使用ページ（既定は標準名前空間、1ウェーブ）。

## 外部リンクの付け替え `urlRename`

サイトの移転などに合わせて、外部リンクのURLを付け替えます（BOTREQの `http://旧 |https://新`）。

| 改名元 | 付け替える範囲 | 例 |
|---|---|---|
| `/` で終わる（例: `http://old.example/`） | そのURLで始まるURLすべて | `http://old.example/a/b` → `https://new.example/a/b` |
| `/` で終わらない（例: `http://example.com/page`） | そのURLそのものと、続きが `/` `?` `#` のURL | `…/page`・`…/page/sub`・`…/page?a=1` は対象、`…/page2` は対象外 |

- `[URL 表示]` の外部リンク、素のURL、`{{Cite web|url=…}}` などのテンプレート引数のいずれも対象です。
- スキーム（http/https）とホスト名の大文字・小文字は区別しません。`www.` 付きなど、直前に文字が続く別のURLは対象外です。
- **http:// と https:// の両方の旧URLを付け替える**（チェックボックス。画面では既定でオン）: 改名元が `http://旧` でも、`https://旧` で書かれたリンクも同じ旧URLとして付け替えます。対象ページも http と https の両方で検索して合わせます。オフにすると、改名元に書いたスキームのURLだけが対象です。
- **対象**: 外部リンク検索（`list=exturlusage`。Special:LinkSearchと同じ）。2ウェーブ（ウェーブ1でTemplateを先に直す）。

## カスタム `custom`

自分で書いた正規表現で置換します。

- **置換ステップ**: 正規表現（JavaScriptの `RegExp`）・フラグ（既定 `g`）・置換後の文字列（`$1` などが使えます）。複数のステップは上から順に適用します。
- **対象ページの取得方法**:

| 方法 | 内容 |
|---|---|
| 手入力 | ページ名を1行に1つ |
| カテゴリメンバー | 指定カテゴリのメンバー |
| リンク元（backlinks） | 指定ページへのリンク元 |
| テンプレート使用ページ（embeddedin） | 指定テンプレートの使用ページ |
| 正規表現検索（insource:） | CirrusSearch の検索クエリ（例: `insource:/旧テンプレ/`）。検索がエラーになっても0件として処理を続け、実行ログに警告を残します。 |

1ウェーブで処理します。
